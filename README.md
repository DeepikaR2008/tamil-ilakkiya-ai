# Tamil Ilakkiya AI — Data & Backend Knowledge Base

A citation-grounded literary knowledge base and semantic retrieval engine for Classical Tamil Literature, powered by **FastAPI**, **ChromaDB**, and **Multilingual Sentence Transformers**.

This repository forms the **Data & Backend** subsystem of the *Tamil Ilakkiya AI* project, delivering an authenticated, verse-level indexed corpus for downstream Retrieval-Augmented Generation (RAG).

## 2. Canonical Literary Schema Specifications

Every record in the raw dataset must follow a strict, structured schema with original Tamil text. No synthetic, guessed, or LLM-generated verses are permitted.

### A. Thirukkural
- **Target Count**: Exactly 1,330 Kurals across 133 Chapters (10 Kurals per chapter).
- **Structure**:
  - Aram (*அறத்துப்பால்*): 38 Chapters
  - Porul (*பொருட்பால்*): 70 Chapters
  - Inbam (*காமத்துப்பால்*): 25 Chapters
- **Record Schema**:
```json
{
  "id": "thirukkural_1",
  "text": "அகர முதல எழுத்தெல்லாம் ஆதி\nபகவன் முதற்றே உலகு.",
  "metadata": {
    "work": "Thirukkural",
    "section": "Aram",
    "chapter_number": 1,
    "chapter_name": "கடவுள் வாழ்த்து",
    "verse_number": 1,
    "poet": "திருவள்ளுவர்",
    "literary_type": "Kural"
  }
}
```

### B. Sangam Anthologies (Purananuru, Akananuru, Natrinai, Kuruntokai)
- **Expected Counts**:
  - Purananuru: 400 poems
  - Akananuru: 400 poems
  - Natrinai: 400 poems
  - Kuruntokai: 401 poems
- **Record Schema**:
```json
{
  "id": "purananuru_182",
  "text": "உண்டால் அம்ம இவ்வுலகம் இந்திரர்\nஅமிழ்தம் இயைவது ஆயினும் இனிதுஎனத்\nதமியர் உண்டலும் இலரே...",
  "metadata": {
    "work": "Purananuru",
    "poem_number": 182,
    "verse_number": 182,
    "poet": "கடலுள் மாய்ந்த இளம்பெருவழுதி",
    "thematic_category": "பொதுவியல்",
    "literary_type": "Sangam Poem"
  }
}
```

### C. Tamil Epics (Silappathikaram & Manimekalai)
Preserves authentic Epic Kandam/Kaathai structure (not artificial poem numbers).
- **Silappathikaram Schema**:
```json
{
  "id": "silappathikaram_1_1",
  "text": "திங்களைப் போற்றுதும் திங்களைப் போற்றுதும்...",
  "metadata": {
    "work": "Silappathikaram",
    "kandam": "புகார்க் காண்டம்",
    "kaathai": "மங்கல வாழ்த்துப் பாடல்",
    "chapter_number": 1,
    "verse_or_section": "1-3",
    "poet": "இளங்கோவடிகள்",
    "literary_type": "Epic"
  }
}
```
- **Manimekalai Schema**:
```json
{
  "id": "manimekalai_1_1",
  "text": "தெய்வந் தொழாஅள் கொழுநற் றொழுதெழுவாள்...",
  "metadata": {
    "work": "Manimekalai",
    "kaathai": "விழாவறை காதை",
    "chapter_number": 1,
    "verse_or_section": "1-5",
    "poet": "சீத்தலைச் சாத்தனார்",
    "literary_type": "Epic"
  }
}
```

## 3. Installation & Setup

### Step 1: Install Python Dependencies
```bash
pip install -r requirements.txt
```

### Step 2: Place Source Data
Place your verified Tamil source JSON files into `data/raw/`:
- `data/raw/thirukkural.json`
- `data/raw/purananuru.json`
- `data/raw/akananuru.json`
- `data/raw/natrinai.json`
- `data/raw/kuruntokai.json`
- `data/raw/silappathikaram.json`
- `data/raw/manimekalai.json`

*(To test the pipeline immediately with sample authentic verses, run `python scripts/setup_sample_verified_corpus.py`)*

## 4. Execution Pipeline

### Step 1: Clean and Normalize Data
Strips any residual markup, cleans whitespace, enforces Unicode NFC normalization, and validates record identifiers:
```bash
python scripts/clean_data.py
```
Output files are written into `data/processed/`.

### Step 2: Validate Corpus Integrity
Strictly validates against canonical counts and reports any missing, duplicated, or corrupted verses:
```bash
python scripts/validate_data.py
```
Example Output:
```text
============================================================
Corpus Validation Report — Tamil Ilakkiya AI
============================================================
Thirukkural       : 1330 / 1330 (133 chapters validated)
Purananuru        : 400 / 400
Akananuru         : 400 / 400
Natrinai          : 400 / 400
Kuruntokai        : 401 / 401
Silappathikaram   : structure validated
Manimekalai       : structure validated
============================================================
[+] All available corpora successfully verified against canonical counts & schema.
============================================================
```

### Step 3: Build ChromaDB Vector Database
Generates high-dimensional multilingual embeddings using `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` and persists the collection `tamil_ilakkiya_corpus`:
```bash
python scripts/build_database.py
```

## 5. Running the FastAPI Backend

Start the API server:
```bash
uvicorn backend.main:app --reload --host 0.0.0.0 --port 8000
```
Interactive API docs will be available at: `http://localhost:8000/docs`.

### API Endpoints

#### 1. Search Endpoint: `POST /search`
**Request Payload:**
```json
{
  "query": "அறம் என்றால் என்ன?",
  "top_k": 3,
  "work_filter": "Thirukkural"
}
```

**Response Format (Directly consumable by Member 2's RAG pipeline):**
```json
{
  "query": "அறம் என்றால் என்ன?",
  "total_results": 3,
  "results": [
    {
      "id": "thirukkural_1",
      "text": "அகர முதல எழுத்தெல்லாம் ஆதி\nபகவன் முதற்றே உலகு.",
      "work": "Thirukkural",
      "section": "Aram",
      "chapter_number": 1,
      "chapter_name": "கடவுள் வாழ்த்து",
      "verse_number": 1,
      "poet": "திருவள்ளுவர்",
      "literary_type": "Kural",
      "score": 0.8942,
      "distance": 0.1058,
      "metadata": {
        "work": "Thirukkural",
        "section": "Aram",
        "chapter_number": 1,
        "chapter_name": "கடவுள் வாழ்த்து",
        "verse_number": 1,
        "poet": "திருவள்ளுவர்",
        "literary_type": "Kural"
      }
    }
  ]
}
```

#### 2. Health Check: `GET /health`
Returns database readiness and total indexed count.

#### 3. Corpus Statistics: `GET /corpus/stats`
Returns total document counts and storage details.

## 6. Downstream Integration (For Team Members)

- **Member 2 (AI / RAG Pipeline)**:
  - Query `POST http://localhost:8000/search` with the user query.
  - If `results` are empty or top score is below confidence threshold (e.g. `< 0.65`), trigger the honest abstention mechanism (*"I don't have enough evidence from the literary corpus"*).
  - Format retrieved verses and citations (`work`, `chapter_name`, `verse_number`) into the LLM prompt.

- **Member 3 (Frontend / UI)**:
  - Connect user query box to backend search or RAG endpoint.
  - Render the **Evidence / Why this answer?** card showing `verse_number`, `work`, `chapter_name`, `poet`, and the original Tamil text.
